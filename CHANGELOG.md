## 1.0.0 - 2026-10-07

Initial release of ParkerLabel.

- CPU-based, MobileSAM-assisted annotation with AI, Manual, and Inspect modes.
- Object detection and instance segmentation annotations with COCO-compatible saving.
- Nine interface languages, configurable keyboard shortcuts, and persistent settings.
- Portable macOS arm64 and Windows x64 packages with bundled models for offline use. Preserve `configs/` when upgrading.
- Manual update checks with GitHub Releases and Baidu Netdisk download links.
