# PyQt5 corresponding source

Parker Label distributes the GPL v3 edition of PyQt5 5.15.11. The complete
source archive used for this version is available from the PyQt5 5.15.11
release files on PyPI:

- Archive: `PyQt5-5.15.11.tar.gz`
- SHA-256: `fda45743ebb4a27b4b1a51c6d8ef455c4c1b5d610c90d2934c7802b5c1557c52`
- Project page: `https://pypi.org/project/PyQt5/5.15.11/#files`

Download the source distribution rather than the prebuilt wheel and verify it
with:

```bash
shasum -a 256 PyQt5-5.15.11.tar.gz
```

The GPL v3 text supplied in that source archive is copied as
`LICENSE.GPLv3` in this directory. The application source and its packaging
inputs are identified by the release Git tag and `build-info.json`.
