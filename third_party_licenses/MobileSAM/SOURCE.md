# MobileSAM model source

The runtime model is derived from MobileSAM commit
`ce9ce32c068c10a21cc96c0e433ce67eac75dcb5` and its official
`weights/mobile_sam.pt` checkpoint.

- Original checkpoint size: `40,728,226` bytes
- Original checkpoint SHA-256: `6dbb90523a35330fedd7f1d3dfc66f995213d81b29a5ca8108dbcdd4e37d6c2f`
- Repository: `https://github.com/ChaoningZhang/MobileSAM.git`

The Apache License 2.0 and TinyViT notices are copied in this directory.
Complete ONNX export commands, tool versions, output hashes, and validation
records are in `docs/model-provenance.md` in the Parker Label source release.
