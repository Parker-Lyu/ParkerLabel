# Lucide canvas icons

Source: https://github.com/lucide-icons/lucide/tree/66d8f9fc394b8530377e5f6112f0b8908ba01280/icons

The `parker_label_app/assets/canvas-icons/` directory contains the original SVG files
`house`, `zoom-in`, `zoom-out`, `eye`, `eye-off`, `scan-eye`, `undo-2`, `redo-2`,
`square-plus`, `square-x`, and `square-check-big`. The adjacent PNG files are
rendered from those SVGs with `builds/render_canvas_icons.py` at 24, 48, and
72 pixels for 1x, 2x, and 3x displays using the interface color `#344054`.
The upstream license is in `LICENSE`.
